# Scopefirst

Use this pack before you write code. One client, one folder, then send the scope for a written yes.

The pack includes the message you paste to the client, a change-request sheet, and a filled example (Nova Clinics) so you can see a finished kickoff.

## Order of work

1. Copy this folder and rename it with the client name.
2. Fill `01-discovery-call.md` on the call.
3. Same day, fill `02-scope-one-pager.md` and `03-estimate-sheet.md`.
4. Paste `07-message-to-client.md`, attach those two files, and wait for a reply.
5. After they agree, fill `04-tech-decision.md` and `05-week-one-plan.md`, then start the repo.
6. At launch, run `06-handoff-checklist.md`.
7. If they add work later, use `08-change-request.md` before you build it.

## Files

| File | Use when |
|------|----------|
| `01-discovery-call.md` | First call |
| `02-scope-one-pager.md` | What you will and will not build |
| `03-estimate-sheet.md` | Hours, three price bands, deposit |
| `04-tech-decision.md` | Stack, in writing |
| `05-week-one-plan.md` | First five working days |
| `06-handoff-checklist.md` | Launch and ownership |
| `07-message-to-client.md` | Email or chat after the call |
| `08-change-request.md` | New work after sign-off |
| `examples/nova-clinics/` | A completed discovery, scope, and estimate |

## Rule

Do not open the repo until the client has replied to the scope. Verbal "sounds good" on a call is not sign-off.
